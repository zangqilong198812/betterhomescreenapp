# How to Add Widgets

1. Press and hold any empty space on the Home Screen, then tap the **Edit** button in the top-left corner.

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/en/IMG_0066-portrait.png)

2. Select **Add Widget** from the pop-up menu.

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/en/IMG_0067-portrait.png)

3. Enter **Minimalist** in the search bar.

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/en/IMG_0068-portrait.png)

4. Swipe to select the widget you want to use.

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/en/IMG_0069-portrait.png)
