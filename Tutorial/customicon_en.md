# Customize iPhone App Icons

1. ## Download theme resources to the Files app  

- In the minimalist app, select the theme you like ,click Download.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0002-portrait.png)

- After successful download, a sharing window will pop up—click Save to Files.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0003-portrait.png)

- Open the Files app.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0006-portrait.png)

- In **Recents**, you can find the theme file just downloaded—click to extract it.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0007-portrait.png)

1. ## Set up custom icons in Shortcuts  

- Open Shortcuts.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0009-portrait.png)

- Tap the ➕ icon in the top-right corner to create a new shortcut.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0010-portrait.png)

- In the search actions bar, search for "Open App."  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0011-portrait.png)

- Tap App and select the app you want to replace.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0012-portrait.png)![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0013-portrait.png)

- Tap the title at the top to **Rename** the shortcut to the corresponding app name.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0014-portrait.png)

1. ## Add shortcuts to the home screen  

- Tap Add to Home Screen.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0014-portrait.png)

- Select "Image" here.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0017-portrait.png)

- Tap Choose File.  

From the pop-up window, select the extracted theme folder.  

Browse the "icons" folder and pick your preferred icon.  

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0016-portrait.png)

- Tap Add to complete the replacement.

![img](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/Resource/en/IMG_0018-portrait.png)
