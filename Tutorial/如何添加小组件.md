# 如何添加小组件

1. 长按主屏幕上的任意位置，并轻点左上角**编辑**按钮

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/cn/IMG_0070-portrait.png)

2. 弹出的菜单中选择 **添加小组件** 

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/cn/IMG_0059-portrait.png)

3. 在搜索框中输入 **极简桌面**

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/cn/IMG_0060-portrait.png)

4. 滑动选择您需要使用的小组件

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/cn/IMG_0061-portrait.png)
