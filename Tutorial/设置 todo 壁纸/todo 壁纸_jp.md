# Todo 壁紙を自動変更するショートカットの設定

## 1. インストール済みのショートカットを編集する

ショートカットアプリで、先ほどインストールしたショートカットを開きます。

![](https://p.ipic.vip/n1reqk.PNG)

操作の検索で **壁紙** と入力します。
![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/wallpapertutorial/cn/IMG_1005-portrait.png)
ショートカットに追加をタップします。

* ロック画面とホーム画面の壁紙を同時に変更することもできますが、ここではロック画面の壁紙のみを選択することをおすすめします。

![](https://p.ipic.vip/c18om8.PNG)

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/wallpapertutorial/cn/IMG_1006-portrait.png)



## 2. 置き換えたいロック画面の壁紙を設定する

矢印で示された位置をタップします。

![](https://p.ipic.vip/dguvy0.PNG)

お使いのスマートフォンに複数のテーマデスクトップが存在する場合があるため、ショートカットの **壁紙** をタップし、壁紙リストから置き換えたいものを選択します。

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/wallpapertutorial/cn/IMG_0987-portrait.png)

ここで注意してください、矢印をタップして、プレビューの表示を閉じるか、または主体に切り取ります。
![](https://p.ipic.vip/3cqd7q.PNG)

## 3. オートメーションの作成

編集が完了したら、ショートカットでオートメーションをタップします。次に「新しいオートメーション」ボタンをタップしてください。

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/wallpapertutorial/cn/IMG_0981-portrait.png)

## 4. オートメーションタイプの選択

オートメーションには複数のタイプがありますが、ここでは **App** を選択します。

![](https://p.ipic.vip/p2elhf.PNG)

## 5. オートメーションの設定

ここではオートメーションの実行タイミングを設定します。minimalist を閉じたときに壁紙を更新するようにします。理由は簡単で、Todo の状態を設定したいときに、アプリに入ってから出ると壁紙が更新されるからです。また、下の「すぐに実行」を選択するように注意してください。

![](https://p.ipic.vip/n9vj9z.PNG)

## 6. オートメーションで実行するショートカットの選択

次へをタップすると、オートメーションは実行するショートカットを選択するように求めます。ここで先ほどインストールしたショートカットを選択します。

![](https://p.ipic.vip/6pxvdx.PNG)

## 7. 設定完了

これで全ての設定が完了しました。minimalist に入ってから退出するたびに、ロック画面の壁紙が最新の Todo 壁紙に更新されます。

![](https://p.ipic.vip/fo9fr0.png)
