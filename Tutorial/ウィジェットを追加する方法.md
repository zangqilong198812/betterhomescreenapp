# ウィジェットの追加方法

1. ホーム画面を長押しし、左上の**編集**ボタンをタップ

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/jp/IMG_0062-portrait.png)

2. 表示されたメニューで**ウィジェットを追加**を選択

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/jp/IMG_0063-portrait.png)

3. 検索ボックスに**Minimalist**と入力

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/jp/IMG_0064-portrait.png)

4. 使用するウィジェットをスワイプして選択

![](https://rtquickidea.oss-cn-beijing.aliyuncs.com/besttheme/TutorialPic/widget_tutorial/jp/IMG_0065-portrait.png)
