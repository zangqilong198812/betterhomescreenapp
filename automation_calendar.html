Year Progress Calendar Wallpaper

Automation tutorial

This wallpaper updates automatically and is ideal for a life calendar or visualizing the progress of the current year.

Step 1: Create an automation

  • Open the Shortcuts app and go to the Automations tab.
  • Create a new automation and select the Time of Day option.
  • Set the time for 6:00 AM and repeat daily.
  • Select Run Immediately so it runs in the background.
  • On the next page, select Create New Shortcut.

Step 2: Get the wallpaper link

  • Open your browser and go to thelifecalendar.com .
  • Click on the wallpaper you want to install.
  • Choose the layout style and iPhone model. Use the default Days layout and select a larger iPhone model for a clean look.
  • Copy the URL provided near the end of the installation steps.

Step 3: Add Shortcut actions

  • Search for the action Get Contents of URL and paste the link you copied.
  • Add the action Set Wallpaper Photo and fill out the fields.
  • Select an existing lock screen to replace.
  • Set Wallpaper Location and uncheck Home Screen so only the lock screen changes.
  • Toggle off Show Preview and Crop to Subject.
  • To set the wallpaper for the first time, click the play button on the bottom sheet.

Optional: For a more minimal look, use the Black & White style in lock screen customization.
