How to Add Widgets

Tutorial

  1. Press and hold any empty space on the Home Screen, then tap the Edit button in the top-left corner.
  2. Select Add Widget from the pop-up menu.
  3. Enter Minimalist in the search bar.
  4. Swipe to select the widget you want to use.
